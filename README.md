📊 Sales Performance Dashboard

Overview

An interactive web-based Sales Performance Dashboard built to analyze sales, profit, orders, products, and business performance using a modern BI-style interface.
The dashboard converts raw sales data into interactive KPIs and visual insights for better business decision-making.

🚀 Features

•	Total Sales, Total Profit, Total Orders & Average Order Value
•	Monthly Sales Trend
•	City-wise Sales
•	Category-wise Performance
•	Sales Representative Performance
•	Profit vs Sales Analysis
•	Discount Impact on Profit
•	Payment Method Distribution
•	Top 5 & Bottom 5 Products
•	Interactive Date, City, Category & Sales Rep filters
•	Responsive design for desktop and mobile
•	Excel/CSV file upload support
•	Interactive hover tooltips

🛠️ Technologies Used

•	HTML5
•	CSS3
•	JavaScript
•	Chart.js – Data visualization
•	SheetJS (XLSX) – Excel/CSV data processing
•	GitHub Pages – Deployment
│
📊 Dataset

The dataset contains:

Order_ID, Order_Date, Customer_Name, City, Region, Product_Category, Product_Name, Sales_Rep, Units_Sold, Unit_Price, Total_Sales, Payment_Method, Discount_%, Profit
